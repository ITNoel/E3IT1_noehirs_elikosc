# E3IT1_noehirs_elikosc
Das Projekt/Programm stellt eine Fahrzeugverwaltung dar,
es bietet die Möglichkeit verschiedene Fahrzeuge anzulegen und diese über einen Mietvertrag zu buchen.
Der Mietvertrag kann auch den Gesamtpreis der Buchung berechnen.

Zum starten des Projektes die Datei "start.py" öffnen und ausführen
